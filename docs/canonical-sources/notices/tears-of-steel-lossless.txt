This is a lossless copy of the short film "Tears of Steel".

This directory contains a set of 1920x800 8-bit png files
at 24 frames per second from the original render of the
film released 2012 September 26.

"Tears of Steel", code-named "mango" during development,
was a Blender Open Movie Project. It developed a open vfx
pipeline for compositing computer generated elements with
live action video.

See http://mango.blender.org/ for more information.
