************** Nocturne filmgrain assets Readme **************************************

This is the readme for the Nocturne assets with added film grain.

The assets covered in this readme can be browsed on the Netflix OpenContent
bucket here:
http://download.opencontent.netflix.com.s3.amazonaws.com/index.html?prefix=Nocturne/nocturne_filmgrain/

3840x2160, 60 fps

HDR version:
PQ P3 D65, 4000 nits (same as source)
synthetic grain was created using Filmbox. Grain only (halation disabled).
Vision3 base stock, with a modified strength to a value of 1.2.
Output Apple ProRes 422

SDR version:
Conversion to 709 with ACES version 2.0
